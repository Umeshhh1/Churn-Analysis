Customer Churn Analysis & Prediction:
--------------------------------------

This project analyzes 64,000+ customer records to identify churn behavior and key factors influencing customer retention. Data was cleaned and transformed using SQL, followed by exploratory data analysis and feature engineering in Python. Machine Learning models were applied to predict customer churn and identify high-risk customers.
An interactive Power BI dashboard was developed to visualize churn rate, customer segments, KPIs, and retention trends, enabling stakeholders to explore insights and make data-driven decisions.

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Tools & Technologies:

   • SQL – Data cleaning, transformations and KPI generation

   • Python (Pandas, NumPy, Matplotlib) – Data analysis and churn prediction
   
   • Power BI – Interactive dashboards and data visualization.

   • Machine Learning – Random Forest Model for churn prediction.

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------


Business Impact:

   • Identified high-risk churn customers, enabling targeted retention strategies.

   • Provided actionable insights on key churn drivers such as usage patterns and customer segments.

   • Enabled business teams to monitor churn KPIs in real time through Power BI dashboards, supporting proactive decision-making and improved customer retention.
